Transition Lab

Uma transformação visual que conecta tecnologia, justiça e sistemas.

Objetivo

Construir uma sequência reversível entre três ilustrações: computador, Têmis e engrenagem.

Problema explorado

Como comunicar a passagem de uma ideia para outra por meio de formas vetoriais, mantendo a transformação compreensível nos dois sentidos.

Solução

O navegador combina componentes SVG, interpolação de contornos e mudanças graduais de opacidade. O controle da demonstração avança entre os estados e permite retornar às formas anteriores.

Tecnologias

  • HTML semântico
  • CSS responsivo
  • JavaScript no navegador
  • SVG

Demonstração

A demonstração abre em uma página própria do portfólio.
